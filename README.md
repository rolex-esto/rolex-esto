<details>
<summary><b>📖 Project details</b></summary>

<br/>

**BizPilot** — An all-in-one operations hub for Filipino online sellers, built to fix fragmented customer conversations, payment verification, inventory management and sales operations. Includes a grounded AI sales assistant, conversational ordering, operations calendar sync and secure data isolation.

**OpsPilot** — Separates observation from inference, evaluates competing hypotheses, and uses an 8-category evidence model. When evidence is too thin to establish a root cause, it returns `INSUFFICIENT_EVIDENCE` instead of guessing.

**BahaRoute** — Flood-aware route decision support for Metro Manila / NCR. A decision-support prototype; it never guarantees a route is safe or passable.

**Weather Weather Lang** — Turns weather data into a conversational decision-support experience for commuters, using iterative AI-agent quality evaluation. Ulan Ba? served as its reference architecture.

**Ulan Ba?** — GPS-based location detection, hourly rainfall and severity forecasts, multi-city comparison, Best Time to Go recommendations, smart typhoon alerts, responsive cross-platform UI.

**Classic Flagship Store** — Admin, cashier and customer dashboards, point-of-sale, shopping cart, real-time inventory sync, automated low-stock alerts, Google OAuth, Gemini-powered assistant, PDO prepared statements, SPF/DKIM/DMARC email authentication.

</details>
